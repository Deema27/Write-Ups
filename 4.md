## Summary

### Challenge 1: Sherlock 01FE00CF

The user downloaded and executed `Preventivo24.02.14.exe.exe` from a Dropbox link via Mozilla Firefox, likely disguised as a legitimate program. Once run, the malware spread additional malicious files throughout the system, including `once.cmd` at:

```
C:\Users\CyberJunkie\AppData\Roaming\Photo and Fax Vn\Photo and vn 1.1.2\install\F97891C\WindowsVolume\Games\once.cmd
```

The malware also **tampered with file timestamps** (e.g., changing a `.pdf` file's creation time to `2024-01-14 08:10:06`) to conceal its activity. It then sent DNS requests to `www.example.com` to verify internet connectivity before contacting a **C2 server at `93.184.216.34`**. The process terminated itself at `2024-02-14 03:41:58`, having left behind a backdoored version of UltraVNC on the system.

---

### Challenge 2: Sherlock 014900A4

The `CyberJunkie` user first logged in at `27/03/2023 14:37:09 UTC`. They then:

1. Added a custom **outbound firewall rule** named `Metasploit C2 Bypass` — likely to facilitate C2 communication.
2. Modified the system audit policy, specifically the **Other Object Access Events** subcategory.
3. Created a scheduled task called **HTB-AUTOMATION** that runs `C:\Users\CyberJunkie\Desktop\Automation-HTB.ps1`.
4. Installed **SharpHound** (`SharpHound-v1.1.0.zip`) from the Downloads folder, which was detected and **quarantined** by Windows Defender.
