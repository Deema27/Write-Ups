## Reconnaissance

### Machine 10.129.8.60

Running an Nmap scan against the target revealed that the **SMB service** was accessible on port `445/tcp`, indicating that the machine was likely exposing Windows file shares over the network.

**Command Used**

```bash
nmap -sC -sV 10.129.8.60
```

The service enumeration scripts and version detection confirmed SMB accessibility, making SMB enumeration the next logical step during reconnaissance.

## Target Interaction

### Commands Used

#### Machine 10.129.8.60

* Used `smbclient` to enumerate available SMB shares anonymously.
* Connected to the `Config` share without credentials.
* Downloaded `config.ini` from the share.
* Used `crackmapexec` to validate the discovered credentials.
* Used `evil-winrm` to gain remote PowerShell access to the target.

### Interactions with Target

#### Machine 10.129.8.60

1. Enumerated SMB shares anonymously using `smbclient`.

```bash
smbclient -L //10.129.8.60 -N
```

The enumeration revealed several accessible shares, including a share named `Config`.

<img width="823" height="374" alt="image" src="https://github.com/user-attachments/assets/ade0b91f-a8ca-4d3e-b9a9-619fad784ea4" />


---

2. Connected to the `Config` SMB share without authentication.

```bash
smbclient //10.129.8.60/Config -N
```

This confirmed that the share allowed anonymous access.

<img width="942" height="289" alt="image" src="https://github.com/user-attachments/assets/1e4d4951-3746-428a-a61c-52f5dd3b072a" />


---

3. Listed files within the share and discovered `config.ini`.

```bash
ls
```

The presence of a configuration file suggested that sensitive information such as usernames or passwords might be stored inside.

<img width="942" height="289" alt="image" src="https://github.com/user-attachments/assets/53f215a0-47b1-418c-ae42-5705d7860d19" />



---

4. Downloaded `config.ini` from the SMB share.

```bash
get config.ini
```

The file was successfully transferred to the local machine for analysis.

<img width="932" height="114" alt="image" src="https://github.com/user-attachments/assets/587aa11a-5987-4a56-b5b2-3e0bf8c329a6" />


---

5. Exited the SMB session and viewed the contents of the file locally.

```bash
exit
cat config.ini
```
<img width="800" height="539" alt="image" src="https://github.com/user-attachments/assets/cb4d3666-1522-4184-bd87-e767d10c0ea1" />

The configuration file contained plaintext credentials for a valid user account.

| Field    | Value         |
| -------- | ------------- |
| Username | `claudio`     |
| Password | `PurpleHaze!` |


---

6. Validated the discovered credentials using `crackmapexec`.

```bash
crackmapexec smb 10.129.8.60 -u claudio -p 'PurpleHaze!'
```

The tool confirmed that the credentials were valid against the target system.

<img width="785" height="540" alt="image" src="https://github.com/user-attachments/assets/897a0e8e-648e-4361-862b-fd85a1eb9aa8" />


---

7. Used the valid credentials to establish a remote PowerShell session through Evil-WinRM.

```bash
evil-winrm -i 10.129.8.60 -u claudio -p 'PurpleHaze!'
```

A successful WinRM connection provided interactive command execution on the target machine.
