## Target Interaction

### Commands Used

#### Machine 014400A1

- Used `ftp` to connect and logged in as the **anonymous** user (no password required).

#### Machine 014700A4

- Used `smbmap` to enumerate shares. Discovered a `C:\` share on the machine, though the current user did not have access.

| Machine | Vulnerability |

| 014700A4 | Unprotected Administrator login via SMB (no password set) |

### Interactions with Target

> 📸 _Add screenshots of ALL target interactions below_

#### Machine 014400A1

1. Gained FTP access using the anonymous user.
2. Ran `ls` to list files in the target directory — discovered `flag.txt`.
3. Switched the FTP download directory to the local PWNBOX temp directory.
4. Used `get` to download `flag.txt`.
5. Exited the FTP session.
6. `cd`'d to the temp directory.
7. Used `cat` to read and capture the flag.

#### Machine 014700A4

1. Used `crackmapexec` — found that user **aartjan** had the password `123456`.
2. Attempted `smbmap` with `aartjan` — **insufficient access** to `C:\`.
3. Tried `smbmap` with the **Administrator** account and no password — access granted to `C:\`.
4. Listed files on `C:\`, including the `Users` folder.

## Target Navigation

### Machine 014700A4

Using the unprotected Administrator account:
